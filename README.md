# 🤖 Nobitex AI Scalper Pro v1

## سیستم معاملاتی هوشمند خودمختار برای صرافی نوبیتکس

سیستمی جامع برای تشخیص سیگنال‌های طلایی، پیش‌بینی روند قیمت، و معاملات خودکار در بازار رمزارزها.

### ✨ ویژگی‌های اصلی

- 🎯 **تشخیص سیگنال‌های طلایی** - الگوریتم‌های پیشرفته برای سیگنال‌های قوی
- 📊 **تجزیه فنی بلادرنگ** - RSI, MACD, Bollinger Bands, VWAP
- 🔄 **معاملات خودکار** - سیمولیشن معاملات با مدیریت ریسک
- 📈 **پیش‌بینی روند** - پیش‌بینی قیمت و جهت بازار
- 🛑 **سپر دفاعی و تریلینگ** - مدیریت خودکار سود و زیان
- 📱 **الرت Telegram** - اطلاع‌رسانی بلادرنگ
- 🎨 **Dashboard مدرن** - رابط کاربری فارسی زیبا
- 📊 **تحلیل چند‌نماد** - پوشش 100+ رمزارز

### 🚀 شروع سریع

```bash
# 1. نیاز‌مندی‌ها
pip install -r requirements.txt

# 2. تنظیم Telegram (اختیاری)
export TELEGRAM_BOT_TOKEN="your_token"
export TELEGRAM_CHAT_ID="your_chat_id"

# 3. اجرا
python run_strategy_Version1.py
```

### 📋 نیاز‌مندی‌ها

- Python 3.8+
- Tkinter (معمولاً نصب‌شده است)
- پکیج‌های مورد نیاز (requirements.txt)

### 🎮 نحوه استفاده

1. **شروع سیستم**: کلیک بر دکمه "شروع"
2. **تنظیم پارامترها**: 
   - تریلینگ (%)
   - فعال‌سازی تریلینگ (%)
   - سپر دفاعی (%)
   - آستانه طلایه

3. **مانیتور کردن**: 
   - نمای کلی: تمام نمادها
   - سیگنال‌ها: سیگنال‌های تشخیص‌شده
   - اتو ترید: معاملات شبیه‌سازی‌شده

### 📊 تب‌های Dashboard

| تب | توضیح |
|---|---|
| **نمای کلی** | تمام نمادها و شاخص‌های فنی |
| **سیگنال‌ها** | تمام سیگنال‌های تشخیص‌شده |
| **سیگنال 2** | سیگنال‌های بهبودیافته (حالت اختیاری) |
| **اتو ترید** | معاملات خودکار شبیه‌سازی‌شده |

### ⚙️ تنظیمات اصلی

```python
# قوانین سیگنال
MIN_LOG_SCORE = 6              # امتیاز حداقل برای ثبت
MIN_RULES_FOR_SIGNAL = 2       # حداقل قوانین منطبق
SIGNAL_COOLDOWN = 15 * 60      # تاخیر بین سیگنال‌ها

# طلایه
TALAYE_MIN_SCORE = 0.78        # آستانه طلایه
TALAYE_MIN_SCORE_V2 = 0.85     # آستانه نسخه 2
TALAYE_VOL_FACTOR = 2.0        # ضریب حجم

# معاملات
AUTO_TRADE_USDT_VALUE = 10.0   # ارزش هر معامله
LEVERAGE = 20                  # اهرم
TRAILING_PERCENT_DEFAULT = 2.0 # تریلینگ
STOP_LOSS_PCT_DEFAULT = 0.3    # سپر دفاعی
```
